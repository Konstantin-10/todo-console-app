# Todo List Console Application

Консольное приложение для управления списком задач, реализованное на Python.  
Поддерживает добавление, удаление, просмотр и отметку задач как выполненных.  
Данные сохраняются между запусками в JSON-файл.

---

## Функциональность

- Просмотр списка задач
- Добавление новой задачи
- Удаление задачи с подтверждением
- Отметка задачи как выполненной
- Хранение данных между запусками приложения

---

## Технологии

- Python 3.9+
- JSON (хранение данных о задачачх)
